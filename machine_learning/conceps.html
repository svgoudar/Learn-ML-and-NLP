Below is a complete, structured list of all major concepts in Machine Learning. This is the “concept map” interviewers expect you to know—similar to hyperparameters, generalization, regularization, etc.

I’ve grouped them into 15 concept categories for clarity.

1. Core Learning Concepts#

  • Model

  • Parameters

  • Hyperparameters

  • Loss function

  • Optimization

  • Underfitting / Overfitting

  • Bias–variance tradeoff

  • Generalization

  • Regularization

2. Data Concepts#

  • Features (Feature Engineering)

  • Labels / Targets

  • Feature scaling (standardization, normalization)

  • Handling missing data

  • Data distribution

  • Outliers

  • Train/Validation/Test split

  • Cross-validation

3. Types of Learning#

  • Supervised Learning

  • Unsupervised Learning

  • Semi-supervised Learning

  • Self-supervised Learning

  • Reinforcement Learning

  • Online Learning

  • Transfer Learning

4. Model Families#

  • Linear models (LR, Logistic)

  • Tree-based models (RF, XGBoost)

  • Kernel methods (SVM)

  • Instance-based models (kNN)

  • Probabilistic models (Naive Bayes, HMMs)

  • Neural networks (CNN, RNN, Transformers)

5. Optimization Concepts#

  • Gradient descent

  • SGD, Mini-batch GD

  • Momentum

  • Adam, RMSProp

  • Learning rate scheduling

  • Loss landscape

  • Convergence

6. Regularization Techniques#

  • L1 / L2 regularization

  • Dropout

  • Early stopping

  • Data augmentation

  • Ensembling (bagging, boosting)

  • Weight decay

  • Batch normalization (acts partly as regularization)

7. Evaluation Concepts#

For classification:#

  • Accuracy

  • Precision

  • Recall

  • F1 score

  • ROC-AUC

  • Confusion matrix

For regression:#

  • MSE, RMSE

  • MAE

  • R² score

For clustering:#

  • Silhouette score

  • Davies–Bouldin index

8. Probability & Statistics Concepts#

  • Distributions

  • Expectation, variance

  • Covariance, correlation

  • Bayes’ theorem

  • Maximum likelihood estimation (MLE)

  • MAP estimation

  • Gaussian Process

  • Entropy, KL divergence

9. Model Complexity & Capacity#

  • Hypothesis space

  • VC-dimension

  • Expressiveness

  • Curse of dimensionality

  • Margin (SVM)

10. Feature Representation#

  • Embeddings

  • One-hot encoding

  • TF-IDF

  • Word/Document embeddings (Word2Vec, BERT)

  • Dimensionality reduction (PCA, t-SNE, UMAP)

11. Pipeline & Workflow Concepts#

  • Data cleaning

  • Feature engineering

  • Model training

  • Hyperparameter tuning

  • Model evaluation

  • Deployment

  • Monitoring

  • Retraining

  • Drift detection (data drift, concept drift)

12. Interpretability & Explainability#

  • Feature importance

  • SHAP

  • LIME

  • Partial dependence plots

  • Counterfactual explanations

13. Scalability & Production ML#

  • Distributed training (Spark, Ray)

  • GPU/TPU acceleration

  • Online inference

  • Batch inference

  • Model versioning (MLflow, DVC)

  • Latency / Throughput

  • A/B testing

14. Advanced ML Concepts#

  • Attention mechanism

  • Transformers

  • Sequence modeling

  • Reinforcement learning concepts (Policy, Value function, Q-learning)

  • Meta-learning

  • Active learning

15. Security, Fairness & Ethics#

  • Adversarial attacks

  • Privacy (DP, federated learning)

  • Fairness metrics

  • Bias mitigation
